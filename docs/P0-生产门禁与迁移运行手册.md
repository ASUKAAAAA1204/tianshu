# P0 生产门禁与迁移运行手册

## 启动门禁

生产模式必须同时满足：

```powershell
$env:LP_ENV = "production"
$env:LP_BOOTSTRAP_PASSWORD = "至少12位的一次性初始化密码"
powershell -ExecutionPolicy Bypass -File .\scripts\start-production.ps1
```

生产模式禁止 `DEMO_MODE=true`，禁止使用 `admin123`。数据库初始化时会使用 `LP_BOOTSTRAP_PASSWORD` 创建初始角色账户；完成首次登录后应立即修改密码并轮换该环境变量。

## 会话与注销

- 登录令牌只以 SHA-256 摘要写入 `sessions` 表，原始令牌只返回给客户端。
- 服务重启、进程扩容后会话仍可验证；注销会删除对应会话。
- `LP_SESSION_TTL_SECONDS` 默认为 8 小时，可按试点安全策略缩短。

## SQLite 迁移

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\migrate.ps1
```

当前迁移版本为 5，包含持久化会话表。迁移前备份 `data/platform.db`；若迁移异常，停止服务后恢复备份，再定位具体迁移语句。

## PostgreSQL/PostGIS

1. 使用 `docker compose -f docker-compose.postgres.yml up -d` 启动验证环境。
2. 生产环境必须显式设置 `POSTGRES_PASSWORD`，不得使用 compose 默认值。
3. 初始化 SQL 按 `001` 至 `006` 顺序执行；新增迁移必须同时更新 `schema_migrations` 记录和回滚说明。
4. 上线前至少完成一次备份恢复演练和一次连接故障演练。

## 发布判定

- 竞赛演示：允许 SQLite + `start.ps1`。
- 封闭试点：使用 PostgreSQL/PostGIS、Caddy/Nginx TLS、集中日志和备份。
- 正式商用：除上述要求外，还需完成并发、长稳、灾备及运维告警验证。
