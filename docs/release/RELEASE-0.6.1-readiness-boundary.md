# 0.6.1 恢复版验收边界

更新时间：2026-10-16

## 已验证

- SQLite demo/pilot：33 项 Python 单测、演示数据校验、API 表面烟测、前端契约烟测通过。
- 二维地图：MapLibre 模式实际截图可见任务、飞行器、空域、设施、主航线、备用航线和实际轨迹；SVG 为离线回退模式。
- 前端交互：Playwright 2 条规格通过，覆盖地图初始化、航线存在、放大、高度层、图层开关和对象摘要点击。
- 截图证据：Playwright 固定 `1366x768` 视口并生成 `test-results/maplibre-1366x768.png`。
- 权限：admin、dispatcher、observer、auditor 登录/会话/退出通过；observer/auditor 写接口拒绝通过。
- 遥测：轨迹顺序、CSV 导出、隔离数据库和时间倒退拒绝通过。
- 数据边界：空间资产、空域单元、设施和 DEM 均标注 `synthetic_demo` 或公开参考边界。
- PostgreSQL/PostGIS 实机：Docker 容器连接、迁移版本 17、任务/图层/指标查询、业务流程和备份恢复演练通过；当前容器端口为 `55432`。
- 业务闭环 API：任务创建、详情、规则检查、航线生成、人工采用、飞行启动/推进、事件处置和完成状态已通过 PostgreSQL 烟测。
- 设施主数据 API：新增、编辑、维护状态、停用和审计已通过 PostgreSQL CRUD 烟测。

## 未宣称完成

- 长期稳定性、生产安全配置和真实授权数据：当前只完成单次 PostgreSQL/备份恢复演练，未完成持续压力、故障切换和正式数据接入验收。
- 完整业务流程的浏览器级 E2E：API 闭环已通过，但 Playwright 尚未覆盖任务全流程操作页面。
- 独立设施管理工作台：后端 CRUD 已完成，前端当前仍以设施状态查询为主，尚缺独立的增删改停用页面和批量导入交互。
- 决赛三维建模、Cesium、三维路径搜索和 AI 优化：按项目范围暂未纳入本恢复版。

## 发布判断

当前版本适合比赛演示、SQLite 封闭试点及已验证的 PostgreSQL 集成测试，不应描述为已完成正式商业交付。正式商业发布前仍需完成长稳/故障恢复、浏览器级全流程 E2E、设施管理工作台和正式授权数据验收。
