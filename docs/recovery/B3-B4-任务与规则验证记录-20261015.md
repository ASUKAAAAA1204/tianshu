# B3/B4 任务管理与规则检查验证记录

核验日期：2026-10-15

## B3 任务管理

- 任务创建：通过，HTTP 201；
- 任务详情：通过，HTTP 200；
- 起点、终点、飞行器和计划高度：通过；
- 时间窗口写入数据库并在详情返回：通过；
- 重复任务编号：返回 HTTP 409 / `MISSION_EXISTS`；
- 非法任务编号：返回 HTTP 422 / `INVALID_MISSION_ID`；
- 不完整时间窗口：返回 HTTP 422 / `INCOMPLETE_TIME_WINDOW`。

本轮修复：任务创建 INSERT 补齐 `time_window_start` 和 `time_window_end`，避免后端已校验但数据丢失。

## B4 规则检查

- 软约束航线：返回 `warning`，提示人工确认；
- 硬约束航线：返回 `blocked`；
- 硬约束航线生成：返回 HTTP 409 / `ROUTE_BLOCKED`；
- 规则检查结果包含规则编码、等级、消息和处置动作；
- 规则结果写入任务检查记录和审计日志。
