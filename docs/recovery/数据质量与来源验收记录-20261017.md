# 数据质量与来源验收记录（2026-10-17）

## 范围

仅检查当前二维演示/参考数据，不下载或替换数据，不覆盖 SQLite 数据库。三维、建筑碰撞和真实飞行安全数据不在本轮范围内。

```powershell
python scripts/validate-demo-data.py --write-manifest
python scripts/validate-demo-data.py --check-manifest
python -m unittest discover -s tests -q
```

## 未完成与限制

- `data/source/dem/N30E107.hgt.gz` 和 `N30E108.hgt.gz` 均未找到；本轮不将合成 DEM 标记为真实 DEM。
- 当前环境未安装 Shapely；脚本检查 GeoJSON 坐标和环闭合/非零面积，不验证多边形自相交及完整拓扑有效性。
- 当前没有建筑数据，因此不能验证建筑高度，也不提供建筑碰撞结论。
- 数据清单只覆盖脚本 `DATA_FILES` 中的九个数据文件，不包含数据库、日志、临时数据或本清单自身。
- OSM 数据依 ODbL 1.0 提供，页面保留署名；本记录不构成数据授权审查或运营许可。

## 可重复验证

- `python scripts/validate-demo-data.py`：只读校验。
- `python scripts/validate-demo-data.py --write-manifest`：校验并重写 `data/spatial-data.sha256`。
- `python scripts/validate-demo-data.py --check-manifest`：校验数据文件哈希未漂移。
- `python -m unittest discover -s tests -q`：验证数据校验拒绝畸形坐标/环，并回归后端测试。
