### A 级：可直接使用

文件完整存在，并已有当前测试或运行证据。

### B 级：可由补丁重建

补丁中包含完整 Add File 内容，但当前目录缺失。需要按同一基础版本重放，并重新测试。

### C 级：有修改片段但缺基础文件

只有 Update File 补丁，且目标文件当前不存在或版本不匹配。需要先从相邻补丁、远程版本或会话输出重建基础文件。

### D 级：只有文字描述

历史会话只说明“已完成”，没有完整补丁、文件或运行输出。不能直接视为恢复依据。
