# P1 质量与运维验收清单

## 已落地

- 前端内联样式和内联脚本拆分为 `spatial.css`、`shell.js`。
- HTML CSP 已收紧为同源脚本和样式，禁止对象加载和跨源连接。
- 统一安全响应头增加 Permissions-Policy、Cross-Origin-Opener-Policy；生产模式增加 HSTS。
- POST 接口增加单节点滑动窗口限流，可通过 `LP_RATE_LIMIT_WINDOW_SECONDS` 和 `LP_RATE_LIMIT_MAX_REQUESTS` 调整。
- 新增 `/api/metrics`，返回运行时间、任务、告警、会话和请求计数。
- 新增 SQLite/PostgreSQL 备份恢复脚本。
- 新增健康接口并发冒烟脚本。

## 验收命令

```powershell
python -m unittest discover -s tests -v
python -m compileall -q backend
node --check frontend/app.js
python scripts/db_backup.py .\backups\platform.db
python scripts/load-smoke.py http://127.0.0.1:8765 50
powershell -ExecutionPolicy Bypass -File .\scripts\migrate-postgres.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\seed-postgres-demo.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\p1-postgres-restore.ps1
```

恢复必须显式确认：

```powershell
python scripts/db_restore.py --confirm .\backups\platform.db
```

## 尚未关闭的商业风险

- 当前限流是单节点内存实现，多实例需下沉到网关或 Redis。
- 标准库 HTTP server 仍建议由 Caddy/Nginx 反代，不能直接暴露公网。
- 路线规划仍是演示级可解释算法，不能作为飞行规划认证结论。
- 24 小时长稳、真实备份恢复和 PostgreSQL 容器升级验证仍需现场执行并留证。
