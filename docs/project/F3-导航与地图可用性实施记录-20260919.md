# F3 导航与地图可用性实施记录

实施日期：2026-09-19  
对应计划：`docs/project/前端整改迭代计划-UX验收闭环-20260919.md`

## 本轮目标

让操作员知道自己当前在哪个模块，并为地图提供低噪声、可键盘操作的业务对象入口；不把底图道路和大量 SVG/MapLibre 图形暴露给辅助技术。

## 已完成

- 导航按钮继续使用 `aria-current="page"`，点击后滚动到对应模块标题并自动聚焦。
- 新增导航定位播报区域，明确告诉用户已定位到态势、任务、规则或机队模块。
- SVG 地图视觉层整体设置 `aria-hidden="true"`，避免道路和参考图层污染可访问性树。
- MapLibre 视口设置 `aria-hidden="true"`，保留视觉交互但不让辅助技术遍历底图节点。
- 新增地图业务对象键盘入口，可操作飞行器、设施、空域/空间对象并打开对应详情。
- DEM 按钮增加 `aria-pressed` 状态。
- 坐标读数增加操作说明和状态播报。
- SVG 与 MapLibre 两种地图模式均补充业务对象入口。
