# P2 设施约束与逐段复核前端接入

## 本阶段完成内容

- 设施主数据进入航线候选评分：起点、终点分别检查附近可用起降/备降/运行中心设施；
- 检查兼容机型、服务半径和设施状态；
- 设施覆盖不足作为可解释软约束参与候选评分，不替代法定审批，也不静默阻断任务；
- 航线规划结果返回 `facility_checks`，候选方案可比较设施覆盖提示；
- 前端态势页显示设施数量和设施状态摘要；
- 任务详情新增“逐段复核”入口，按段展示距离、高度、硬冲突、软冲突和段级决策；
- 保留演示数据边界，设施数据仍标记为 `synthetic_demo`。

## 验证结果

- Python 单元测试：50 项通过；
- 前端 TypeScript 类型检查：通过；
- 前端静态检查：通过；
- HTTP 烟测：航线规划返回 2 项设施检查，逐段复核返回 1 段结果；

## 商用边界

- 当前设施约束仍属于规划辅助规则，尚未接入授权设施台账、真实开放时段和容量占用流水；
- 当前前端提供态势展示和逐段复核入口，尚未完成独立设施管理工作台；
- 正式商用前仍需完成 PostgreSQL 真实容器迁移、设施导入校验、并发容量锁定、权限细分和生产稳定性验证。
