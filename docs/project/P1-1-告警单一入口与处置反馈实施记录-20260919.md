## 一、本轮目标

解决顶部优先告警与告警中心重复提供处置动作的问题，形成“优先告警提示 → 告警中心统一处置 → 任务/地图/时间线刷新”的单一入口闭环。

## 二、已完成

- 顶部优先告警仅保留“进入告警中心”入口，不再重复提供“立即处置”。
- 点击入口后自动滚动到告警中心，并将焦点移到首个告警动作，便于键盘操作。
- 告警中心继续承载“查看影响”和“标记已处置”两个真实动作。
- 保留处置确认、备注、操作者、时间和结果面板反馈。
- 新增 E2E：验证顶部与告警中心不存在重复处置入口，且焦点转移正确。
