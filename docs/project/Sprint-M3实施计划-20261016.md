# Sprint M3：地理数据准入与约束解释

日期：2026-10-16  
基线：M2 时间轴完成

## 目标

将 DEM、空间资产、空域和建筑数据的来源、版本、坐标系、覆盖范围及生产可用性明确呈现在平台中；对当前离线 DEM 指标和合成空间对象给出可解释边界。M3 不把合成数据升级成真实授权数据。

## 参考与边界

- QGroundControl 地形/任务统计作为“地形指标靠近航线结果”的交互参考；不复制飞控或地形服务。
- ArcGIS Mission 图层元数据和任务上下文作为来源展示参考；不宣称拥有其 GIS 服务能力。
- 本项目质量约束：数据源登记、许可状态、版本、坐标系、覆盖范围、更新时间和生产准入状态必须可读。

## 任务

| ID | 内容 | 完成定义 |
|---|---|---|
| M3-01 | 数据登记模型 | 前端呈现 DEM、空间资产、空域参考、建筑数据的来源/版本/坐标系/覆盖/状态 |
| M3-02 | 约束解释 | 明确 DEM 只用于演示净空指标；建筑碰撞和权威授权判断显示未接入 |
| M3-03 | 地形结果联动 | 航线检查/规划结果显示样本数、起始高程、最大高程、净空阈值及合成数据边界 |
| M3-04 | 空间图层来源 | 空域、设施、障碍物详情显示 source_kind/data_version/时间字段，缺失显示未提供 |
| M3-05 | 质量验收 | 测试覆盖来源面板、未接入建筑声明、缺失字段、MapLibre/SVG和三种视口截图 |

## 不在本轮

真实授权空域、真实许可、在线底图、可追溯公开 DEM 下载、建筑矢量/3D 模型、建筑碰撞安全结论、Cesium 和 AI 路径规划均需外部数据准入及独立专题，不在 M3 宣称完成。

## 完成门槛

用户只看界面即可判断哪些数据是合成演示、哪些算法使用了 DEM、哪些能力未接入；不出现“实时”“权威”“已完成碰撞校验”等误导文案。
