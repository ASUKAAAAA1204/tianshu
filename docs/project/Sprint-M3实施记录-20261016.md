# Sprint M3 实施记录（2026-10-16）

## 1. 本轮目标

将地理数据的“是否可用、来源边界、版本状态和约束影响”直接呈现在运行态势界面中，避免把合成演示数据误解为真实授权空域、真实测绘或建筑碰撞能力。

## 2. 已完成

### 2.1 地理数据准入面板

- 在左侧新增“地理数据准入”区域。
- 展示 DEM、高程、空域与限制、建筑数据三类数据状态。
- DEM 明确标注为“离线合成网格”“WGS84”“DATA-DEMO”“仅规划演示”。
- 空域与限制明确标注为“公开参考 / 合成”，并提示未登记为权威许可。
- 建筑数据明确标注“未接入”，并说明建筑碰撞与建筑净空不参与判定。

### 2.2 地图对象可追溯字段

- 空域、限制区、设施等空间对象详情增加数据版本字段。
- 未提供版本时显示“未提供”，不伪造权威版本号。

### 2.3 DEM 约束结果解释

- 数据检查结果接入现有离线 DEM 指标：起点高程、最高高程、地形起伏、最小净空、采样数和阈值。
- 结果明确标注“DEM参考 · 合成演示”。
- 当 DEM 不可用时，明确显示未接入、无法进行地形净空判断和合成数据边界。
- 结果中增加正式运行前需替换为已授权数据的提示。

## 3. 参考与边界

- 参考了 QGroundControl 任务/地形统计的“指标随任务结果展示”思路，以及 ArcGIS Mission 的数据上下文与元数据表达方式。
- 本轮未接入在线底图、真实授权空域、真实 DEM、建筑矢量/三维模型、碰撞检测、Cesium 或真实 AI 路径规划。
- 所有当前结果仍属于公开参考 / 合成演示数据，不能作为真实飞行许可或安全放行依据。

- `node --check frontend/app.js`：通过。
- `npm run test:e2e`：3/3 通过。
  - MapLibre 工作区与数据准入展示：通过。

## 5. 未完成项
