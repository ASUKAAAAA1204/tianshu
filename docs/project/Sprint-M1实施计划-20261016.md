# Sprint M1：航线层级、标签避让与对象反馈

日期：2026-10-16  
基线：Sprint M0 实施结果  
依据：[二维地图板块目标与成熟产品对比及调整方案](./二维地图板块目标与成熟产品对比及调整方案-20261016.md)

## 1. 目标与边界

解决地图要素拥挤和对象被点选后反馈不足的问题，让用户能识别主/备用/模拟实际航线、重要对象及需要人工核查的原因。实现仅处理当前任务及其空间对象；所有演示内容仍明确标记为公开参考/合成演示数据。

本轮不接入地图时间轴、真实DEM或建筑数据，不实现Cesium/三维、AI航线规划或真实运行控制；不把合成风险解释描述为真实安全结论。

## 2. 参考项目与改动映射

## 4. 验收矩阵

- 缩放和平移地图时标签重新计算，不遮挡关键航线；标签不互相覆盖，地图上的标签可读且不阻断拖动。
- 低缩放设施簇有数量和可访问名称；点击后放大到展开；风险对象始终单独可见并可选。
- 点选飞行器、设施、空域/限制区和风险对象，地图符号和右侧详情同步；风险说明引用实际提供的数据字段，不提供虚构处置建议或授权判断。
- 主航线、备用航线、模拟实际轨迹和风险航段有不同视觉编码；无风险字段/事件时不得绘制风险段。
- MapLibre 与 SVG 回退的对象选择流程均通过；浏览器无 uncaught page error；所有E2E仍使用隔离数据库。
- 三种视口无横向溢出、标签裁切或控件遮挡。截图检查作为自动化断言以外的必要验收证据。

## 5. 风险与降级

- 若标签过密，按“选中对象、风险、航线端点、设施”顺序保留，次级标签隐藏但对象仍可通过地图符号/对象列表选择；不得移动对象点位。
- 若MapLibre聚合插件API与锁定版本不符，使用MapLibre GeoJSON source 原生 clustering；不引入新地图库。
- SVG回退不做地理统计聚类，采用相同优先级的屏幕网格聚合与对象列表入口；若暂不能等价，实现中需明确差异，不伪称双引擎完全一致。
- 任何数据字段来源不明时显示“未提供/合成演示”，不通过UI推断真实风险。
