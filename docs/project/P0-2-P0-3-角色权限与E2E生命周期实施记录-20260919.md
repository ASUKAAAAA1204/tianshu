# P0-2 / P0-3：角色权限与 E2E 生命周期实施记录

实施日期：2026-09-19  
对应计划：`docs/project/质量与可用性整改计划-20260919.md`

## 一、本轮目标

关闭 P0-2 的角色演示不透明问题，并修复 P0-3 中因异步登录、地图引擎切换和测试进程残留造成的假失败与后续套件污染。

## 二、已完成

### 1. 角色权限回归

- 新增 `observer` 浏览器回归：顶部显示“观察员”，设施管理入口保留但禁用，并显示“需调度员/管理员”提示；任务详情仍可只读查看。
- 新增 `dispatcher` 浏览器回归：顶部显示“调度员”，设施工作台可进入，任务检查动作可见。
- 保留 `admin` 原有完整演示路径，并继续作为 E2E 默认账号。

### 2. 登录等待竞态修复

- E2E 登录助手不再在 `page.goto()` 后立即读取登录层可见性。
- 改为等待运行时元数据完成后，在“登录层已显示”或“任务数据已渲染”之间做确定性判断。
- 登录完成后统一等待首个任务条目可见，避免只验证静态标题导致未登录页面误通过。

### 3. 地图测试隔离

- MapLibre 专项继续使用默认 `?map=maplibre`。
- SVG 渲染专项显式使用 `?map=svg`，避免把 SVG DOM 断言施加到 MapLibre 容器上。
- SVG 业务对象与标签节点不再共享资产类型 class，避免同一对象被 DOM 计数两次。
