# Sprint 3：遥测历史与实际轨迹回放实施记录

实施日期：2026-09-19  
对应阶段：Sprint 3 运行模拟

## 本轮目标

把任务运行数据从“仅保留最新遥测快照”升级为“可查询、可回放、可在地图上表达的实际轨迹”。本轮仍严格限定为模拟/设备适配器输入，不触发自动飞行控制。

## 已完成

- SQLite 新增 `telemetry_samples` 表与第 17 个迁移；
- PostgreSQL 新增 `013_telemetry_samples.sql`，包含唯一约束和任务/会话/序号索引；
- 模拟飞行启动、每次推进、标准遥测接入均写入历史采样；
- `GET /api/missions/{id}/telemetry` 返回当前快照与有序 `track`；
- 任务详情包和 `/api/bootstrap` 为任务附带最新飞行会话及 `track`；
- SVG 地图优先使用历史采样绘制实际轨迹，只有无历史采样时才回退到当前位置连线；
- 保留现有遥测字段、告警与人工确认边界，不改变现有接口语义。

## 数据边界

当前轨迹来自 `source=simulator` 或适配器提交的 `source=device` 字段。演示环境仍标注“公开参考 / 合成演示数据”，不代表真实授权空域、真实飞行许可或真实设备飞行记录。
