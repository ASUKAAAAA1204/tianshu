# Sprint M4：二维遥测轨迹回放与数据基线验收（2026-10-17）

## 范围

本轮只处理二维运行地图、已记录遥测回放和公开参考/合成数据核验；不实现 Cesium、三维地形/建筑建模或三维路径规划。

## 已实现

- 新增地图内轨迹回放条，支持按采样点拖动、播放和暂停，并显示采样时间与可用点数。
- 回放数据来自任务遥测历史接口；MapLibre 与 SVG 地图同步使用所选采样点更新飞行器位置和实际轨迹。
- 回放只构造前端显示副本，不覆盖 bootstrap 中的实时车辆状态或数据库采样。
- 根据截图复核移除了地图上的飞行器/设施/风险名称框，地图仅保留语义图标；名称与详情由地图对象摘要、右侧详情提供。对象摘要改为受限高度自动换行，避免横向滚动条挤占地图区域。
- 无飞行会话的既有任务返回 `available: false` 与空采样列表；不存在的任务仍返回 `MISSION_NOT_FOUND`。
- 回放条并入地图坐标/数据边界栏，保留 1366×768 首屏运行时间轴可见性。
- 地理演示数据增加校验和清单核验，具体资产数量、合成 DEM 与缺失来源见《数据质量与来源验收记录-20261017.md》。

## 未完成与边界

- 轨迹回放当前按 600ms/点演示，不按采样时间间隔或速度插值；时间戳仅显示，不代表实时运行时钟。
- 遥测回放是历史态势查看，不连接真实飞控，也不触发任何控制动作。
- DEM 仍为合成网格；SRTM 压缩源缺失，拓扑检查未执行（环境未安装 Shapely）；无权威空域、建筑碰撞数据或真实许可判定。
- 本记录不覆盖 PostgreSQL/生产部署、长期稳定性、灾备、授权数据接入或商业交付门槛。
- 仓库级 `git diff --check` 报告既有计划书末尾多余空行，位置在 `比赛执行计划书-两人团队-梁平低空运行基础底座.md`；该文件未纳入本轮修改。
