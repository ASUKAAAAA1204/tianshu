# Sprint M3-P2 高度、时间、状态表达与演示数据治理计划

## 目标

在 1366×768 首屏中直接呈现高度层、时间窗口和运行状态，并让地图、任务卡和时间轴使用一致的业务语义。只表达当前数据实际支持的内容，缺少数据时显示“未提供”，合成数据清楚标注来源边界。

## 参考

- QGroundControl Plan View：参考任务高度与地图任务对象联动的表达方式。
- MapLibre GL JS：继续使用现有数据驱动图层及 feature 状态表达。
- 本项目既有数据契约：`planned_altitude`、飞行器 `altitude/status/battery`、任务 `time_window_start/time_window_end`、限制区 `valid_from/valid_to`、告警时间。

## 子任务与验收

### P2-01 高度层直接表达

- 将高度选择改成清晰的分段/选项控件，显示当前层和区间单位。
- 地图任务摘要显示计划高度和所属高度层；飞行器标记和详情保持当前高度一致。
- 过滤后图层与计数/状态同步，空结果提示当前筛选无对象。
- 不把 2D 地图伪装成三维高度剖面；真实地形净空仍按 DEM 合成演示边界说明。

验收：至少 0–60m、60–120m、120–300m 三个范围操作后，目标对象显隐正确；当前层有明显选中状态；截图不依赖旁白可读出 120m。

### P2-02 时间轴业务化

- 时间轴区分任务窗口、临时管制、告警、数据更新时间。
- 使用“已结束/进行中/待开始/时间未提供”状态和颜色表达。
- 缺失时间不推测、不生成虚假时间；本地展示时区明确。
- 首屏保持时间轴标题、关键事件卡可见，横向溢出可滚动。

验收：有时间事件时状态、时间、来源可读；无时间窗口时明确显示“时间未提供”；点击事件能联动对象/任务详情。

### P2-03 运行状态语义统一

- 统一待命、已计划、运行中、需确认、失联、低电量、已完成状态颜色和文案。
- 飞行器符号、任务卡徽标、右侧结果状态一致。
- 低电量仅在数据字段达到现有阈值时展示，缺失遥测显示未知。
- 告警与需人工处置不使用绿色正常态。

验收：典型状态颜色和标签在地图、列表、详情间一致；关键文字不只靠颜色区分。

### P2-04 演示数据治理

- 主界面仅保留产品演示任务；测试夹具不得进入演示数据库。
- 演示对象统一显示“公开参考 / 合成演示数据”来源提示。
- 时间轴和结果详情保留来源、数据时间、未知字段提示。
- 不删除用户数据文件；清理仅在确认是当前 demo 数据库测试记录后，以可回滚方式执行。

验收：页面中不出现 API smoke、E2E、B3B4 等测试任务；合成数据边界在首屏清晰可见。

### P2-05 自动化与截图验收

- E2E 覆盖高度过滤、时间轴状态、任务/对象状态语义、合成数据边界。
- 保存 1366×768、1024×768 和 390×844 截图。
- 检查首屏、无横向溢出、无文字遮挡、控制操作后状态确实变化。

## 不在本轮范围

- 真实空域许可、正式航行情报、实时航空器遥测接入。
- 真实 DEM/DSM、建筑模型、建筑碰撞和飞行安全放行。
- Cesium 三维视图、三维高度剖面、AI 路径搜索。
- 无依据推断缺失任务时间或告警时间。
