# P3 设施管理工作台与导入校验

## 已完成

- 前端资源区新增设施管理入口；
- 支持设施新增、编辑、停用；
- 设施管理操作沿用后端角色校验，非 `admin/dispatcher` 不展示管理入口；
- 新增 `POST /api/facilities/validate-import`，仅校验不写库；
- 导入校验覆盖字段完整性、梁平验证区范围、设施类型和批次内编号重复；
- 管理工作台支持粘贴 JSON 进行预校验，返回通过数、错误数和错误明细；
- 设施状态和主数据仍保留来源类型、数据版本和审计边界。
