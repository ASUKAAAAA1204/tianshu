# Sprint M2：地图时间与运行解释

日期：2026-10-16  
依据：M1 完成结果与二维地图目标方案

## 目标

在地图底部增加独立的运行时间带，分别表达任务计划窗口、临时管制有效窗口、告警发生时刻和数据更新时间。时间轴只解释合成演示数据的有效时间，不把审计日志冒充空间时间轴。

## 参考与边界

- 任务窗口和计划状态参考 QGroundControl Plan View 的计划反馈；本项目不实现飞控上传。
- 管制/告警与地图上下文关联参考 ArcGIS Mission；本项目不宣称具备其协同服务。
- 运行对象时间、来源、过期和缺失标记属于本项目数据可信约束。
- 不接入真实时间源、DEM、建筑、Cesium 或 AI 航线规划。

## 任务

| ID | 内容 | 完成定义 |
|---|---|---|
| M2-01 | 时间模型与数据边界 | 统一 ISO 时间解析；缺失显示“未提供”；所有演示时间带显示合成数据和时区 |
| M2-02 | 地图底部时间轴 | 在地图下方显示任务窗口、临时管制窗口、告警点、数据更新时间；不挤压主地图 |
| M2-03 | 时间状态语义 | 区分计划时间、限制有效时间、告警发生时间、数据更新时间；显示已过期/进行中/待开始 |
| M2-04 | 交互 | 点击窗口或告警点同步右侧详情并突出相关对象；无时间数据时提供明确空态 |
| M2-05 | 回退与测试 | MapLibre/SVG 均显示时间轴；测试覆盖窗口、告警点、缺失字段、视口无横向溢出和数据边界 |
| M2-06 | 截图与记录 | 生成三种视口截图和 M2 实施记录，列出未接入真实时间源的限制 |

## 验收门槛

1. 不看代码即可区分任务窗口、管制窗口、告警时刻和数据更新时间。
2. 时间轴不会覆盖地图、航线或右侧详情；1366×768 和 390×844 可读。
3. 告警时间来自事件字段；缺失或合成字段不被包装为实时。
4. 点击时间项有明确反馈，至少更新右侧状态说明；告警项保留人工处置入口。
5. 自动化测试和实际截图均通过后才报告 M2 完成。
