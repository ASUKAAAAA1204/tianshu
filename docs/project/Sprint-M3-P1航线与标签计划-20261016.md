# Sprint M3-P1 航线与标签优化计划

## 目标

按 QGroundControl Plan View 的任务规划表达方式，确保地图上主航线、备用航线、实际轨迹和风险航段能够被直接区分；对象标签不遮挡航线，并能通过引线追溯到对象。

## 子任务

1. 航线视觉分层：主航线青绿色实线、备用航线蓝色虚线、实际轨迹白色细线、风险航段黄色加粗虚线。
2. 航线方向：所有航线使用方向箭头，风险航段也必须保留方向语义。
3. 标签语义：标签显示对象名称与最小必要状态信息，使用半透明胶囊和细引线。
4. 标签避让：保持现有基于航线交叉检测和已占用框检测的布局算法，补充稳定的视觉样式。
5. 选中联动：地图对象与右侧处置结果保持选中状态同步。
6. 自动验收：增加主航线、备用航线和标签层的 DOM/截图验证。

## 不在本轮范围

- 不接入真实航线授权、真实建筑碰撞或三维路径规划。
- 不修改 MapLibre 数据源协议和后端接口。
- 不以增加装饰性图形替代业务语义。

## 验收标准

- 1366×768 截图中三类航线可区分；
- 风险航段可见且方向明确；
- 标签与航线不发生遮挡；
- 地图对象仍可点击并更新处置结果；
- `npm run test:e2e` 全部通过。
