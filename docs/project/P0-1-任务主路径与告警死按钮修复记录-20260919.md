# P0-1：任务主路径与告警死按钮修复记录

实施日期：2026-09-19

## 问题

任务详情使用首页缓存的 `platformData.alerts` 判断主按钮。告警刚被处置或详情接口返回的任务事件与首页缓存不一致时，可能出现“查看待处置告警”按钮，但详情实际没有开放告警，形成无效动作。

## 修复

- 任务详情存在 `events` 字段时，优先使用任务详情中的开放事件作为告警真源；
- 只有列表态任务没有详情事件时，才回退到首页告警快照；
- 无开放告警的 `warning` 任务继续显示“重新执行规则检查”；
- 保留既有权限、按钮选择器和 API 契约。

- 任务详情抽屉回归：通过；
- 无开放告警的 warning 任务主按钮回归：通过。
