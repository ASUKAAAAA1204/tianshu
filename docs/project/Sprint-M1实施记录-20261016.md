## 1. 结论

M1 的二维地图层级、标签可读性和对象反馈已完成并通过自动化验收。本轮没有引入真实地形、建筑、三维或 AI 路径规划；页面仍为公开参考/合成演示数据。

## 2. 已完成

| 项目 | 实现结果 | 对标/参考项目 |
|---|---|---|
| 航线层级 | MapLibre 与 SVG 均使用主航线青绿色实线、备用航线蓝色虚线、模拟实际轨迹白色细线、风险航段按规则出现；主/备/实际加入方向箭头 | QGroundControl Plan View 的航线/任务地图工作流；颜色和风险边界属于本项目决策 |
| 标签避让 | MapLibre 根据投影后的实际屏幕坐标计算候选位置，检测标签互相重叠及与航线相交；标签带引线，无法放置时隐藏次级标签但保留对象点和列表入口 | QGroundControl 的地图任务元素可读性启发；算法为本项目自实现 |
| SVG 回退避让 | SVG 使用相同优先级和候选位置规则，加入航线相交检测；选中风险点/区域显示高亮 | 本项目双引擎一致性与兼容性约束 |
| 设施聚合 | MapLibre 低缩放使用 GeoJSON cluster，显示设施数量标记；点击地图簇放大，近景展开为设施点。风险对象不进入设施簇 | ArcGIS Mission 的地图图层上下文启发；聚合规则为本项目自实现 |
| 选中反馈 | 飞行器、设施、空域/限制区和风险对象在地图符号/区域及右侧详情同步高亮 | DJI FlightHub 2 运营对象上下文、ArcGIS Mission 地图任务关联 |
| 风险解释 | 详情显示对象类型、风险级别、高度/限制、有效时段、数据时间、来源和需人工核验边界 | 本项目数据可信与安全边界要求，不宣称拥有竞品风险模型 |
| 数据安全 | 未提供字段显示未提供；未把合成字段包装为实时、授权或安全结论；测试继续使用隔离临时 SQLite | 本项目质量与数据边界约束 |
