# 前端 UX 复验报告

复验日期：2026-09-19  
复验对象：梁平县域数字空域与低空运行智能服务平台前端控制台  
复验范围：F0—F5 前端整改闭环

## 一、结论

自动化与代码级 UX 门禁通过，比赛演示主路径达到“可重复操作”状态；正式商业交付仍需真实屏幕阅读器、两人角色人工验收和长稳/部署证据，不能把本报告等同于正式商业交付通过。

## 二、整改闭环

| 原问题 | 处理结果 | 证据 |
|---|---|---|
| 演示环境/账号/权限不清 | 已关闭 | F0 实施记录、登录上下文、设施权限提示 |
| 任务主按钮死路 | 已关闭 | F1 实施记录、空告警分支回归 |
| 主动作无进行中反馈 | 已关闭 | F1 结果面板 loading 状态 |
| 告警重复处置 | 已关闭 | F2 顶部只保留查看影响，处置统一到告警中心 |
| 告警缺少确认/备注/审计 | 已关闭 | F2 `/api/events/{id}/resolve` 与审计日志 |
| 抽屉焦点管理缺失 | 已关闭 | F2 键盘回归：焦点进入、Escape、焦点恢复、Tab 循环 |
| 导航点击不可感知 | 已关闭 | F3 `aria-current`、滚动、标题聚焦、播报 |
| 地图无障碍树噪声 | 已关闭（代码级） | F3 SVG/MapLibre 视觉层 `aria-hidden`、业务对象键盘入口 |
| 表单错误依赖服务端 | 已关闭 | F4 就地校验与新增 E2E |
| 飞行器状态不可行动 | 已关闭（演示数据范围） | F4 链路/任务/告警/电量等级/详情入口 |

新增的 UX 回归覆盖：

- 导航 `aria-current`、目标标题聚焦和定位播报；
- 任务编号重复、经纬度越界、时间窗口反向的就地校验；
- 详情抽屉打开后焦点进入关闭按钮，Escape 后恢复原触发按钮。

## 四、人工验收状态

仍需由两名队员完成并留证：

1. observer、dispatcher、admin 三角色真实浏览器验收；
2. Windows 桌面、窄屏和纯键盘完整演示；
3. 至少一种屏幕阅读器实机检查地图和抽屉；
4. 演示主路径录屏：登录 → 选任务 → 检查 → 航线 → 告警 → 重规划 → 人工确认 → 回放；
5. 版本、数据来源和演示环境标签截图冻结。

## 五、发布判定

- 竞赛演示：**允许进入**，主路径和前端自动化门禁已通过。
- SQLite 封闭试点：**条件允许**，需完成角色人工验收和部署前检查。
- PostgreSQL 封闭试点：**沿用后端条件通过结论**，前端不构成阻断。
- 正式商业交付：**不通过**，仍受 TLS/反向代理、多实例会话与限流、24 小时稳定性、灾备和授权生产数据约束。
