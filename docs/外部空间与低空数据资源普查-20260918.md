# 外部空间与低空数据资源普查

**盘点日期**：2026-09-18  
**目标区域**：重庆市梁平区及梁平机场周边  
**结论**：公开渠道已经证明梁平存在可用于低空运行的真实三维底座和低空数字平台，但其原始图层、航线库和空域规则没有发现公开下载入口；比赛研发可先叠加公开数据，生产级数据需要向主管单位或平台运营方申请。

## 1. 梁平本地已被公开报道的高价值资源

### 1.1 地空一体智能地图

重庆市人民政府 2026-09-07 报道披露：

- 全域约 1888 平方公里地形地貌、建筑分布和空域分层已经纳入地图。
- 地图精度为 1∶25000。
- 6000 米以下空域划分为 20 个纵向分层。
- 已开展跳伞、无人机等公共航线仿真约 842 公里。
- 具备实时监控、任务调度和应急响应能力。
- 该资源由梁平实景三维底座和低空数字平台共同支撑。

来源：

- https://www.cq.gov.cn/ywdt/zwhd/qxdt/202609/t20260907_16040538.html

### 1.2 梁平低空数字底座

重庆市人民政府 2024-11-15 报道披露，梁平已经建设面向低空旅游线路开发的空域数字底座系统，具备：

- 高精度三维实景地图。
- 空域要素整合。
- 空域立体时空模型。
- 航线航路方案模拟。
- 虚拟场景仿真飞行。

来源：

- https://www.cq.gov.cn/zwgk/zfxxgkml/zdlyxxgk/ggwh/ly/zxdt/202411/t20241115_13801701.html

### 1.3 梁平低空智联网与运行样本

重庆市人民政府 2025-12-31 报道披露：

- 20 套无人机及自动机库系统覆盖梁平约 1892 平方公里。
- 系统整合无人机、自动机库、管控系统和数据处理中心。
- 已形成“一网统飞、一机多用、一飞多用”的运行体系。
- 已与基层治理平台和智能预案衔接。
- 已积累公路、河道、地灾、森林防火等运行场景和任务样本。

来源：

- https://www.cq.gov.cn/zt/szzqjs/fngxnzl/cszl/aqfxgk/202512/t20251231_15284531.html

可能的对接对象：

- 重庆都梁纵横低空产业发展有限公司。
- 梁平区城市运行和治理中心。
- 梁平区规划和自然资源局。
- 梁平机场及相关运营单位。

## 2. 当前可以直接下载或公开获取的数据

### 2.1 OpenStreetMap / Geofabrik 重庆提取包

可直接获得重庆区域的：

- 道路、铁路、河流、水系。
- 建筑物和地物点位。
- 兴趣点、机场及部分航空设施。
- 土地利用和行政相关对象。

推荐格式：

- `.osm.pbf`：完整 OSM 标签，适合导入 PostGIS。
- `.gpkg.zip`：适合 QGIS、GDAL 和空间数据库处理。
- `.shp.zip`：适合传统 GIS 工具。

来源：

- https://download.geofabrik.de/asia/china/chongqing.html
- https://www.openstreetmap.org/export?locale=zh-CN

状态：可直接下载；必须遵守 ODbL 并保留署名。不能把 OSM 数据包装为权威空域或测绘成果。

### 2.2 Copernicus DEM

可作为梁平地形底层数据：

- GLO-90：约 90 米全球 DEM。
- GLO-30：约 30 米 DEM，当前部分访问需要注册或授权类别。

适合用途：

- 区域地形起伏。
- 初步离地高度计算。
- 三维地图地形底面。
- 航线风险和坡度预估。

不适合直接替代：

- 建筑物高度。
- 电塔、线缆和局部障碍物。
- 起降点安全验收。

来源：

- https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM
- https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Data/DEM.html

### 2.3 USGS / SRTM DEM

可通过 USGS EarthExplorer 获取约 30 米级全球 SRTM 高程数据，适合与 Copernicus DEM 交叉校验。

来源：

- https://earthexplorer.usgs.gov/
- https://www.usgs.gov/centers/eros/science/usgs-eros-archive-digital-elevation-shuttle-radar-topography-mission-srtm

### 2.4 Open-Meteo 高程和气象

可继续用于：

- 指定坐标的地形高程查询。
- 风速、降水、能见度等天气数据接入原型。
- 历史天气和演示任务风险建模。

Open-Meteo Elevation API 使用约 90 米 DEM；因此适合原型和区域参考，不适合作为精细障碍物高程。

来源：

- https://open-meteo.com/en/docs
- https://github.com/open-meteo/open-meteo/blob/main/openapi/elevation.yml

## 4. 现阶段资源分级

### A级：可直接纳入比赛系统

- OSM/Geofabrik 重庆道路、水系、建筑和机场参考数据。
- 梁平边界和机场公开 GeoJSON。
- Copernicus GLO-90 或公开可用的 GLO-30 DEM。
- USGS SRTM 30 米 DEM。
- Open-Meteo 高程与天气接口。
- 已有演示空域 Polygon、任务、设施点和规则数据。

### B级：可用于答辩引用，但需要申请原始数据

- 梁平 1∶25000 地空一体智能地图。
- 20 个垂直空域分层。
- 842 公里公共航线仿真网络。
- 梁平低空数字平台和低空智联网运行数据。

### C级：暂不能作为平台事实写入

- 权威机场净空保护几何，除非获得正式版本。
- 真实可飞/限飞/禁飞空域图层，除非获得授权。
- 真实建筑物、障碍物和通信覆盖精度。
- 任何未脱敏的飞手、设备和任务轨迹数据。

## 5. 推荐执行顺序

1. 立即下载重庆 Geofabrik `.gpkg.zip` 和 `.osm.pbf`，裁剪梁平区范围。
2. 下载或申请 Copernicus/SRTM DEM，生成梁平 30—90 米地形栅格。
3. 将道路、水系、建筑物和机场对象导入 PostGIS。
4. 向梁平区规划自然资源局申请 1∶25000 地空一体地图样例。
5. 向梁平低空数字平台运营方申请 20 层空域和航线样例。
6. 向梁平机场申请净空保护区和飞行安全边界的脱敏版本。
7. 向运营中心申请 3—5 条脱敏任务、遥测和告警回放样本。
8. 将公开数据、授权数据和合成数据在平台中分层标识，不混用。

## 6. 数据申请时必须要求对方确认

- 数据来源、权属和版本。
- 坐标系、投影和高程基准。
- 数据空间精度和更新频率。
- 是否允许用于比赛系统、PPT、截图和视频。
- 是否允许公开引用单位名称。
- 是否需要签署保密或数据安全协议。
- 是否允许导入本地 PostGIS 进行算法验证。
- 数据撤回、删除和失效处理方式。
